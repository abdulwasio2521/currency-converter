# currency-converter
A lightweight, real-time currency converter web application built with vanilla JavaScript. It fetches live exchange rates using a free API, supports over 150 currencies, and features an intuitive interface with dynamic flag updates.

💱 Currency Converter
A sleek, responsive currency converter web application that provides real-time exchange rates for over 150 currencies worldwide. Built with pure HTML, CSS, and JavaScript.

# ✨ Features
~ Live Exchange Rates - Fetches real-time currency data from a free API
~ 150+ Currencies - Supports major and minor currencies worldwide
~ Flag Indicators - Dynamic country flags for each currency
~ Swap Currencies - Quick swap between "From" and "To" currencies
~ Responsive Design - Works seamlessly on desktop and mobile devices
~ User-Friendly Interface - Clean, intuitive, and visually appealing
~ Automatic Conversion - Real-time calculations as you type
~ Error Handling - Graceful handling of invalid inputs

# 🛠️ Technologies Used
~ HTML5 - Semantic markup
~ CSS3 - Custom styling with animations
~ JavaScript (ES6+) - Core functionality
~ Font Awesome - Icons for UI elements
~ Currency API - Real-time exchange rates
~ Flags API - Country flag images
